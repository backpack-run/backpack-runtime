# Backpack Runtime v0.3.0-alpha.1

This prerelease narrows Backpack around one product: making open coding models work well with coding agents and coding workspaces.

## Highlights

- Promotes `backpack launch` to a primary workflow for Codex, Claude Code, OpenCode, Pi, Codex App, and Claude App.
- Adds Pi through its official isolated `models.json` custom-provider mechanism.
- Adds trusted model protocol, context-window, visibility, and per-agent compatibility metadata.
- Refuses agent launch unless coding, tool-calling, protocol, and explicit agent-compatibility requirements are satisfied.
- Hides the tiny SmolLM2 runtime fixture from the default public catalog while retaining it through `backpack models --all` for CI/smoke tests.
- Keeps llama.cpp, verified GGUF installation, persistent sessions, local/SSH compute, Cloud routing, and the OpenAI/Anthropic compatibility layers.

## Intentional breaking removals

The ASR, speech, image/video, generic media-job, projector/vision, managed Python worker, and related CLI/API/client surfaces have been removed. This includes `backpack transcribe`, `backpack speak`, `/v1/audio/*`, and `/api/backpack/v1/jobs*`.

This is an alpha breaking change. Existing model/runtime caches are not deleted; abandoned state files are ignored rather than destructively removed.

## Agent compatibility

Qwen3-Coder 30B A3B is the current execution-supported coding model and is marked `compatible-experimental` for the four CLI agents. Qwen3-Coder Next remains ineligible until tool calling is execution-qualified. Backpack does not claim complete OpenAI or Anthropic API parity.

## Install or update

```powershell
backpack update --prerelease
```

New installations may use the verified installers documented in `docs/install.md`.

# API

Implemented loopback endpoints:

- `GET /api/backpack/v1/health`
- `GET /api/backpack/v1/version`
- `GET /api/backpack/v1/hardware`
- `GET /api/backpack/v1/models`
- `GET /v1/models`

Session, pull-progress, OpenAI chat proxying, audio, and media job endpoints are planned. Non-loopback binding is rejected until authentication is implemented.
